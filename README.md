Tato verze představuje první krok přestavby původní verze 7.0 do nové modulární architektury dle specifikace GeriApp.

- Firebase konfigurace ve vlastní složce
- Příprava na další fáze (paměť, přihlášení, nástroje)

Verze připravena pro další rozvoj.
